# Obecné informace

- Vysvětlivky: U jednotlivých názvů sloupců a polí jsou dostupné vysvětlivky označené ikonou I. Po najetí myší se zobrazí detailní popis dané položky.

![image-20250905-064822.png](<../../../../pages/FONS GALEN/Finance a účetnictví/Modul Finanční analýza/Obecné informace/assets/image-20250905-064822.png>)
- Export: Na vybraných záložkách je možné data exportovat do souboru za pomocí tlačítka Export

![image-20250905-064854.png](<../../../../pages/FONS GALEN/Finance a účetnictví/Modul Finanční analýza/Obecné informace/assets/image-20250905-064854.png>)
- Historická data: Pomocí šipek vlevo/vpravo lze přepínat mezi aktuálním a předchozími roky.

![image-20250905-064924.png](<../../../../pages/FONS GALEN/Finance a účetnictví/Modul Finanční analýza/Obecné informace/assets/image-20250905-064924.png>)
- Aktualizace dat: Data v modulu jsou aktualizována přes noc. Změny vstupních údajů se projeví až následující den.
- Po aktivaci modulu je třeba vyčkat do dalšího dne, než budou vstupní údaje k dispozici a bude možné je editovat.
