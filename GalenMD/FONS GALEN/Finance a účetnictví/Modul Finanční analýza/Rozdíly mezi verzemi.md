# Rozdíly mezi verzemi

| Funkce | Základní verze | Rozšířená verze |
| --- | --- | --- |
| Výchozí údaje (úhradové parametry, hodnota bodu, koeficient navýšení) | ✅ | ✅ |
| Finanční přehled – Limitovaná péče a Plně hrazená péče | ✅ pouze vykázaná data | ✅ navíc sloupec Modelace a modelované řádky (odhad do konce roku) |
| Finanční přehled – Překročení (Kč) a Překročení (%) | ❌ | ✅ včetně barevného zvýraznění |
| Finanční přehled – Péče cizincům | ✅ | ✅ |
| Analytik – Body a unikátní pojištěnci | ✅ | ✅ |
| Analytik – Nákladní pojištěnci | ✅ seznam pojištěnců, ocenění body, ocenění ZUM a ZULP, PURO | ✅ navíc Ocenění celkem, PURO5, Překročení (Kč), MNP poměr (%) a barevné zvýraznění |
| Analytik – Navýšení hodnoty bodu | ❌ | ✅ |
| Analytik – Navýšení koeficientu navýšení | ❌ | ✅ |
| Export do Excelu | ✅ | ✅ |
| Přepínání roků | ✅ | ✅ |
| Vysvětlivky u sloupců | ✅ | ✅ |
